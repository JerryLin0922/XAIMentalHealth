风格
配色
所有图标沿用 moodhub-web 现有品牌：低饱和松绿主色 #2f6f62 + 暖纸感中性背景 + 四项指标既有配色。 同一套几何通过 CSS 渲染为 5 种风格，可随应用浅色 / 深色主题无缝切换。

风格画廊

极简线条

纯描边、无填充，最轻量，适合顶栏与高密度列表。

扁平化

主体填色 + 白色细节线，双色扁平，最通用。

渐变

主体渐变填充，现代有层次，适合营销与启动页。

拟物

渐变 + 投影 + 高光，立体质感，适合卡片主视觉。

手绘

抖动手绘描边（SVG 噪声滤镜），温暖亲和，适合陪伴场景。

平台使用建议

环境建议
网站直接 <img src="svg/..."> 或内联；顶栏用 line / flat，卡片主视觉用 gradient / skeuo。Favicon 用 logo-flat.svg（已对齐现有 favicon）。
移动 App / 小程序SVG 矢量按需缩放；底部标签栏用 line（24px），悬浮「新增」用 add-flat.svg。iOS 可导出 @2x/@3x PNG，Android 用 adaptive-icon 前景。
桌面端菜单 / 工具栏统一 line 风格；窗口图标与关于页用 skeuo / gradient 增强质感。
社交媒体头像 / 封面用 logo-gradient.svg 或 logo-skeuo.svg；圆形头像建议 add / logo 置于圆底。
深色模式切换 data-theme="dark" 即可；几何不变，仅填充色随 --accent 自动反相提亮。

二次定制

每个独立 SVG 已内联颜色，可直接编辑；展示页中的图标通过 CSS 变量 --accent / --accent2 / --detail 着色， 改一处即可全局换色。手绘风格由 SVG feTurbulence 滤镜实现，调 baseFrequency（抖动频率）与 scale（抖动幅度）即可改变手绘感。
