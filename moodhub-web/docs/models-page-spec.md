# 「模型」页面重新设计说明

> 适用范围：`moodhub-web/js/views/models.js`（页面）、`css/styles.css`（样式）、`index.html`（新增详情弹窗容器）、`js/core/models/*`（数据来源，本次不改接口）。
> 目标：让用户在**不牺牲"本地优先"底线**的前提下，完成 **发现 → 比较 → 选择 → 配置 → 管理** 的完整闭环。

---

## 1. 页面核心目标与设计原则

### 1.1 核心目标（按用户优先级排序）

| # | 目标 | 用户问题 | 成功判据 |
|---|---|---|---|
| G1 | **发现** | "我能用哪些模型？各自是什么？" | 一屏内看到全部本地引擎 + 已配置云端模型，未配置的常见服务商也能"看见"并知道怎么开 |
| G2 | **比较** | "该选哪个？" | 能按 隐私 / 能力 / 上下文窗口 / 成本 / 就绪状态 横向对比，并有明确的推荐与理由 |
| G3 | **选择** | "我想让陪伴用它、问答用它" | 每个场景可独立选模型，切换即时生效且可回退 |
| G4 | **配置** | "怎么接上我自己的服务商？" | 一条表单完成新增，缺什么就提示什么，能一键测试 |
| G5 | **管理** | "用得怎么样？哪里失败了？" | 连接可启停/编辑/删除，调用有日志、有失败原因、有实测延迟 |

### 1.2 现状痛点（本次要解决）

1. 单页纵向堆叠，"选模型"和"配连接"混在一起，没有信息层级。
2. **没有模型发现**：只有一个下拉框 + 一个服务商下拉，用户看不到模型本身是什么。
3. **没有比较**：无法对比窗口 / 成本 / 隐私 / 能力。
4. 下拉里云端模型显示"未就绪"，但**无法就地补全**，得跑到页面底部表单里猜。
5. 模型详情（参数、版本、性能、适用场景、使用说明）**完全缺失**。
6. 连接列表无搜索 / 排序 / 分页（当前数量少，但架构要留位）。
7. 日志无法按场景或结果筛选。
8. 无障碍缺口：`select` 无分组、表格无 `<caption>`、状态变化无 `aria-live`。

### 1.3 设计原则

- **本地优先可见**：任何时刻都能一眼看出"现在是不是严格本地"，且**一键可退回本地**。
- **零配置可用**：不配置任何连接也能完整使用——空态要给出"不用配也能用"的明确安抚。
- **诚实标注估算**：厂商宣称的窗口/速度是**估算档位**，必须标注"估算"；只有本机日志产出的延迟/成功率才叫"实测"。
- **隐私一票否决**：外发授权是全局闸门，未开启时云端模型在 UI 上要显示"已授权后才会调用"，不是"可用"。
- **渐进披露**：列表只给决策必需字段，详情抽屉里才放参数、使用说明与实测数据。

### 2.1 分区职责

| 分区 | 回答的问题 | 主要组件 |

| 调用日志 | 跑得怎么样、哪里失败 | 筛选 + 实测统计条 + 表格 |

## 3. 展示内容类型（字段级定义）

### 3.1 模型列表项（卡片/表格行）

| 字段 | 来源 | 说明 |
|---|---|---|
| 名称 | `LOCAL_MODELS[].name` / `connections[].name` | 云端连接用用户自定义的显示名 |
| 厂商 / 服务商 | `vendor` / `provider` | 本地恒为 `MoodHub` |
| 类型徽章 | `privacy` | `本地`（`badge--local`）/ `云端`，**必须带文字**，不靠颜色 |
| 能力标签 | `capabilities` / 场景 `capability` | `陪伴对话` / `智能问答` |
| 上下文窗口 | `estimateWindow(model)` | **标注「估算」**；本地引擎显示「不适用」 |
| 成本档 | `cost` | `免费` / `按量计费` |
| 就绪状态 | `ready` + `missing` | `可用` / `缺少 API Key` / `缺少 baseUrl 或模型名` / `授权后才会调用` |
| 被哪些场景使用 | `store.models.active` 反查 | `陪伴在用` / `问答在用` |

### 3.2 模型详情（抽屉）

| 分组 | 字段 | 数据来源 |
|---|---|---|
| **基本信息** | 名称、厂商、模型 ID、协议 `kind`、隐私级别 | registry / connection |
| **版本信息** | 模型名（即版本标识，如 `deepseek-flash`）、服务商预设提供的候选版本列表 `preset.models`、**文档链接** `docsUrl` | registry |
| **参数说明** | 场景默认参数 `temperature` / `maxTokens`（`chat`: 0.7/400，`qa`: 0.3/900），并说明"当前版本不可在界面调整，属场景预设" | `SCENARIO_PARAMS` |
| **能力** | 支持的场景、协议、是否需要密钥 | registry |
| **性能** | ① **厂商档位（估算）**：窗口估算档、快速档判定；② **本机实测**：调用次数、成功/降级次数、P50/P95 延迟、平均字符 | ① `estimateWindow`；② `MH.models.logs()` 实时计算 |
| **适用场景** | 该模型适合哪个场景 + 一句人话理由 | `SCENARIOS` + `recommend()` |
| **使用说明** | 如何获取 Key（`keyPlaceholder`）、注意事项（`preset.note`，如混元/Claude 的 CORS 与直连限制）、baseUrl | `PRESETS` |
| **外发预览**（仅云端） | 本次请求会打到哪个 URL、带哪些字段，**密钥以 `***` 掩码** | `MH.modelAdapters.previewRequest` |

> **诚实性要求**：任何"厂商宣称"的指标在 UI 上必须带「估算」标签；只有日志派生的指标才能标「实测」。

### 3.3 场景卡

场景名、场景说明、当前模型下拉（含本地/云端全量选项）、推荐模型 + **可读理由**、[用推荐] 按钮、[查看模型详情]。

### 3.4 连接表

名称、服务商 / 模型（版本）、密钥状态（`已存本机` / `仅本次会话` / `未填写`）、启停状态、操作（测试 / 启停 / 编辑 / 删除）。

### 3.5 日志表

时间、场景、模型（含本地/云端标签）、结果（成功 / 降级：错误码 + 原因）、耗时、字符数。顶部统计条：总数、成功、降级、P50、P95。

## 5. 交互方式

| 交互 | 行为 | 反馈 |
|---|---|---|
| **搜索** | 对名称、厂商、模型名、服务商做大小写不敏感子串匹配 | `debounce 200ms`；结果为空显示 `.empty` 空态 |
| **筛选** | 类型（全部/本地/云端）、能力（全部/陪伴/问答）、就绪（全部/可用/未就绪） | 立即重渲染，筛选后页码重置为 1 |
| **排序** | 推荐优先 / 名称 / 窗口（降序）/ 成本（免费优先） | 立即重渲染 |
| **分页** | 每页 6（卡片）/ 10（表格）；上一页/下一页 + "第 x/y 页" | 禁用态按钮 + `aria-disabled` |
| **视图切换** | 卡片 ⇄ 表格 | 按钮 `aria-pressed` 切换 |
| **打开详情** | 点卡片 / 行内「详情」 | 抽屉打开，焦点移到标题，Esc / 遮罩 / 关闭按钮均可关，关闭后**焦点回到触发元素** |
| **切换场景模型** | 场景卡下拉 `change` | 立即 `setActive` + toast + 刷新 |
| **采用推荐** | 「用推荐」 | 同上，并说明采用的模型名 |
| **新增/编辑连接** | 表单（服务商预填 baseUrl 与默认模型名） | 校验失败在字段下方 `.error`；`persistKey` 需重新验证密码 |
| **测试连接** | 行内「测试」/ 表单「测试连接」 | 按钮进入「测试中…」禁用，结束显示耗时或错误码 |
| **启停 / 删除** | 行内按钮 | 启停即时；删除走 `MH.app.confirm`（**不用 `window.confirm`**，避免被 WebView 屏蔽导致"点了没反应"） |
| **清空日志** | 页头按钮 | 立即清空 + toast |
| **链接跳转** | 详情里的服务商文档链接 | `target="_blank" rel="noopener noreferrer"` + 外链图标 + "离开本站"提示 |

## 6. 视觉风格

- **令牌**：沿用现有 CSS 变量（`--surface` `--surface-2/3` `--line` `--line-strong` `--text` `--text-2` `--muted` `--faint` `--accent` `--accent-soft` `--accent-ring` `--ok` `--warn` `--danger` `--radius` `--shadow-1` `--ease`），**不新增颜色**。
- **语义色**：本地 = `--accent`（青绿），云端 = 中性 `--surface-3`，警告 = `--warn`，失败 = `--danger`。
- **排版**：页面标题 `clamp(22px,3.4vw,28px)`；分区标题 12.5px 大写字母间距；正文 14px/1.65。
- **间距**：8px 基准（8/12/16/22），卡片 `padding:18px`，圆角 `--radius`。
- **动效**：卡片入场复用 `view-in`；抽屉 `fade` + 轻微位移；全部 ≤ 200ms，并遵循 `prefers-reduced-motion`。
- **深浅色**：全部使用变量，不写死色值；新增组件不得引入 `#hex`。

## 7. 响应式适配

| 断点 | 布局 |
|---|---|
| ≥1024px | 模型库 3 列网格；详情为**右侧抽屉**（`max-width:520px`）；工具栏单行 |
| 768–1023px | 2 列；详情仍为右侧抽屉（宽度 70vw） |
| <768px | 1 列；详情改为**全屏抽屉**；工具栏纵向堆叠；工具栏 sticky 于分区顶部 |
| <720px | 表格走 `.table-wrap` 横向滚动（与记录/问答页一致，**不做卡片化**，保持全站统一） |
| 移动底栏 | 复用 `index.html` 已有的 `.tabbar`（含"模型"入口），安全区 `env(safe-area-inset-bottom)` |

## 8. 无障碍要求

1. 标题层级：`h1` 页面标题 → `h2` 分区标题 → `h3` 卡片/详情分组，不跳级。
2. 分段导航：`role="tablist"` + `role="tab"` + `aria-selected` + `aria-controls`，支持 ←/→/Home/End 键；面板 `role="tabpanel"` `tabindex="0"`。
3. 模型卡：整卡可聚焦（`tabindex="0"`）并支持 Enter/Space 打开详情；卡内"详情"按钮独立可聚焦，`aria-label` 含模型名。
4. 详情抽屉：`role="dialog"` `aria-modal="true"` `aria-labelledby`，打开时移入焦点并锁定 Tab，关闭后**焦点归还触发元素**；Esc 关闭。
5. 状态变化：隐私开关、场景切换、测试结果通过 `aria-live="polite"` 区域播报（复用 toast 容器 + 一个隐藏 live region）。
6. 表格：`<caption>`（ visually-hidden ）+ `scope="col"`；行操作按钮 `aria-label` 含连接名。
7. 徽章**不能只靠颜色**：本地/云端、可用/未就绪一律带文字。
8. 表单：每个控件有 `<label for>`；错误用 `.error` 并设 `aria-describedby` + `aria-invalid`。
9. 图标一律 `aria-hidden="true"`，图标按钮必须有 `aria-label`。
10. 焦点可见：不移除 `outline`，使用 `:focus-visible`；对比度 ≥ 4.5:1（文本）/ 3:1（控件边框）。

## 9. 与现有系统的集成

### 9.1 数据来源（只读为主）

| 数据 | 来源 | 可变性 |
|---|---|---|
| 本地模型 / 服务商预设 / 场景 / 场景参数 | `MH.modelRegistry`（静态） | 只读 |
| 连接列表（含 session 密钥） | `MH.store.models.connections()` | 增/改/删 |
| 场景当前模型 | `MH.models.activeFor(scenario)` | `MH.models.setActive` |
| 候选列表 / 解析 / 描述 / 推荐 | `MH.models.listFor/resolve/describe/recommend` | 只读 |
| 连通性测试 | `MH.models.test(modelId)` | 只读（有网络副作用，需授权） |
| 调用日志 | `MH.models.logs()` | 只读 / `clearLogs` |
| 外发授权 | `MH.models.privacy.allowExternal()` | `setAllowExternal` |
| 外发预览（掩码） | `MH.modelAdapters.previewRequest` | 只读 |
| 问答上下文预算（推荐用） | `MH.store.prefs.get().qaContextChars` | 只读 |

### 9.2 状态管理

- **持久化状态**（跨刷新）一律经 `store.models` / `prefs`，页面不自建持久字段。
- **UI 瞬时状态**（当前 tab、视图模式、搜索词、筛选、排序、页码、详情 id、表单草稿）存于 `views/models.js` 模块闭包的 `ui` / `form` 对象 —— 模块只加载一次，`MH.app.refreshCurrent()` 重绘视图不会丢失。
- **不引入** 全局事件总线 / 观察者：数据变更后统一走 `MH.app.refreshCurrent()` 全量重绘（数据规模小，成本可忽略）。
- 表单草稿中的 API Key **永不进入持久状态**；`persistKey` 未勾选时只进 `sessionStorage`（`store` 已实现）。

### 9.3 路由

- 主路由沿用现有 `data-route="models"` + `#view-models`（`app.js` 的 `ROUTES` 已含 `models`），**不改动路由系统**。
- 子视图（四个 tab）**不使用 URL 路由**，用页内分段导航 + 模块闭包状态；刷新后回落到默认 tab「模型库」（如需可分享，后续再引入 `#models/connections` 并让 `app.js` 读 hash）。

## 10. 验收标准

- [ ] 未配置任何连接时，页面完整可用，且空态明确写出"本地引擎永远可用"。
- [ ] 模型库能同时看到本地引擎与所有连接；能按类型/能力/就绪筛选，按推荐/名称/窗口/成本排序，搜索命中名称与模型名。
- [ ] 任一模型可打开详情，含：基本信息、版本与候选版本、参数说明、能力、性能（估算 + 实测）、适用场景、使用说明；云端模型额外给出**密钥已掩码**的外发预览。
- [ ] 两个场景可独立切换模型，切换后 toast 反馈，且下拉显示的是切换后的值。
- [ ] 推荐理由为完整中文句子，说明"为什么"（如"问答上下文约 12000 字符，X 窗口足够且相对经济"）。
- [ ] 新增连接：服务商预填 baseUrl 与默认模型名；缺字段时给出字段级错误；勾选保存密钥需重新验证密码；测试按钮给出耗时或错误码。
- [ ] 编辑连接不填密钥时不清空原密钥；把"保存到本机"改回"仅本次会话"后，落盘密钥被清除。
- [ ] 删除连接需确认；删除后使用该连接的场景自动回落到该场景的本地默认模型。
- [ ] 未开启外发授权时，云端模型在 UI 上标记为"授权后才会调用"，且实际调用仍走本地（回归断言已覆盖）。

- [ ] 键盘可完成：切 tab → 搜索 → 打开详情 → 关闭详情 → 切换场景模型 → 保存连接。
- [ ] 深浅色、≥1024 / 768 / <768 三档断点下无横向溢出、无文字截断。

## 11. 边界情况

| 情况 | 期望行为 |
|---|---|
| 零连接 | 模型库仍有 2 个本地引擎；连接区显示空态；推荐本地并说明原因 |
| 已配连接但未开外发授权 | 云端卡显示"授权后才会调用"；推荐仍给本地，理由指向授权入口 |
| 密钥仅本次会话 | 徽章显示"仅本次会话"；刷新后该连接变为"缺少 API Key"，但配置保留 |
| 连接被停用 | 不出现在场景下拉与模型库；日志里的历史记录仍可读 |
| 连接被删除 | 关联场景回落本地默认；session 密钥一并清除 |
| 同一服务商多条连接 | 靠"显示名称"区分，模型 ID 唯一 |
| 自定义连接 baseUrl 为空 | 保存时拦截并提示；测试返回 `MISSING_CONFIG` |
| 名称/模型名超长 | 列表 `text-overflow: ellipsis`，详情完整显示 |
| 日志 ≥50 条 | 表格渲染最近 20 条；统计基于全部 50 条 |
| localStorage 不可用（隐私模式） | 写入失败时 toast 明确提示"无法保存"，不静默失败 |
| 危机文本 | 强制本地（详情与日志均可见 `CRISIS_GUARD`），UI 不做任何"可外发"暗示 |
| 渲染抛异常 | `app.js` 的 `renderRoute` 兜底渲染错误卡 + 重试按钮（已实现） |

## 12. 性能指标

| 指标 | 预算 |
|---|---|
| 整页首次渲染 | ≤ 50ms（DOM 节点 ≤ 400） |
| 搜索输入到列表更新 | 防抖 200ms + 重渲染 ≤ 30ms |
| 打开详情抽屉 | ≤ 30ms（只读现有数据，不发请求） |
| 打开本地模型详情 | 无网络；打开云端详情**同样不发请求**（预览为本地拼装） |
| 日志统计（P50/P95） | O(n log n)，n ≤ 50，可忽略 |
| 内存 | 不缓存模型响应；不引入虚拟滚动（规模 < 100 项） |

## 13. 错误处理

UI 必须将 `manager` 的错误码翻译成"人话 + 下一步"，绝不只显示 `undefined`。

| 错误码 | UI 呈现 | 可否重试 |
|---|---|---|
| `NO_KEY` | "缺少 API Key" + 引导去连接管理填写 | 填后自动恢复 |
| `MISSING_CONFIG` | "缺少 baseUrl 或模型名" | 是 |
| `AUTH` | "密钥无效或已过期（401/403）" | 换 Key |
| `RATE_LIMIT` | "请求过于频繁（429），稍后再试" | 是 |
| `SERVER` | "服务商返回 5xx" | 是 |
| `TIMEOUT` | "20 秒无响应" | 是 |
| `NETWORK` | "网络不可达或 CORS 被拒（常见原因：浏览器直连限制）" | 是 |
| `BAD_JSON` / `EMPTY` | "返回内容无法解析 / 为空" | 是 |
| `NOT_FOUND` | "模型或服务路径不存在（404）" | 检查模型名 |
| `CRISIS_GUARD` | "检测到危机信号，本次强制本地" | 否（设计如此） |
| `BLOCKED_BY_PRIVACY` | "严格本地模式，已改用本地引擎" | 开启授权后可 |
| `QUOTA`（存储） | "本机存储已满 / 超出预算" | 清理后 |

统一规则：云端失败一律**自动降级本地并在界面写明原因**，功能不中断；测试连接**不降级**，直接暴露真实错误。
