# 「.me 人格与记忆」设计说明

> 目标：让智能问答**认识你**——
> 既记得你问过什么（长期记忆），也知道你大概是什么样的人（五大人格），
> 同时不牺牲这个项目的任何一条隐私承诺。

## 1. 目标与非目标

**目标**

1. 用户与 AI 的每一轮问答都被记住，新问题能接得上旧问题；
2. 用五大人格（OCEAN）描述用户的表达倾向，只用来调整语气与侧重；
3. 多来源输入（上传文件 / 粘贴内容 / 本机记录 / 自定义提示词）+ 记忆 + 人格一起进上下文；
4. 一切都在本机完成，可一键清空，可导出可导入。

**非目标**

- 不做心理测评、不输出"你是什么人格类型"这类定性结论；
- 不做用户画像的商品化标签（没有兴趣推荐、没有打分排名）；
- 不因为有了人格就允许更多数据外发——云端模型的两条硬约束不变。

## 2. 结构

```
js/core/me.js                Me 层：人格推断 + 记忆存取 + 上下文组装 + 导出导入
js/core/store.js             三个 localStorage 键：me.personality / me.profile / me.memory
js/core/qa.js                编排：召回记忆 → 组装上下文 → 生成 → 回写记忆与人格
js/core/retriever.js         assemble() 新增 memoryText / personaText 两段
js/core/local-service.js     本地引擎新增 memory 类型事实，回答里显式引用历史
js/views/qa.js               「我的 · .me」面板 + 两个开关 + 导出 / 导入 / 清空
.me/                         磁盘上的私密目录（人格 / 画像 / 记忆）
tools/me-sync.cjs            浏览器导出 ↔ .me 目录 的手动同步
tests/me.cjs                 67 项回归
```

## 3. 五大人格（OCEAN-5）

| 维度 | 高分 | 低分 | 主要信号（部分） |
| --- | --- | --- | --- |
| 开放性 O | 愿意看到多种解释与可能性 | 更想要确定结论 | 为什么 / 原理 / 尝试 / 换个角度；"别解释直接给结论"为负 |
| 尽责性 C | 看重计划、复盘、长期趋势 | 更随性 | 计划 / 规律 / 打卡 / 复盘 / 统计；连续 10 天以上有记录也计入 |
| 外倾性 E | 表达多、常提他人 | 内敛克制 | 朋友 / 聚会 / 团队 / 一起；"一个人 / 不想说话"为负 |
| 宜人性 A | 客气、顾及关系 | 直接就事论事 | 谢谢 / 麻烦 / 可以吗 / 体谅 |
| 神经质 N | 对压力与波动敏感 | 基线稳定 | 焦虑 / 压力 / 睡不着 / 崩溃；压力大、心情低的记录形态也计入；"平静 / 踏实"为负 |

**更新规则**

- 起始 50 分（中性），置信度 0；
- 一次交互的原始信号 `raw ∈ [-6, 6]`，目标值 `target = clamp(50 + raw × 4.5, 2, 98)`；
- 指数滑动平均：`score += (target − score) × α`，其中 `α = 0.34 − 0.2 × confidence`
  —— 样本少时收敛快（早点有个大致判断），证据多了之后越来越稳；
- 置信度 `confidence = min(1, samples / 20)`；
- **没有信号的维度不会被改动**，不会被噪声拉回中性；
- 每个维度保留最近 3 条支撑原话（截断到 40 字），界面与导出都能看到依据。

## 4. 问答记忆

**写入**：`MH.qa.ask()` 成功后调用 `MH.me.record()`，落库一条

```
{ id, at, question(≤500), answer(≤4000), customPrompt(≤300),
  sources(≤6), intent, modelId, privacy, contextChars }
```

- 上限 200 轮，超出丢弃最旧的；
- 命中危机词的那一轮**不写入**（`reason: 'CRISIS'`）；
- 开关只控制"是否参与回答"：关掉「参考历史对话」后不再召回，**但记忆仍照常写入**，
  这样下次打开开关时历史是完整的；关掉「带上我的人格画像」后人格不再更新。
  想彻底不留痕迹，用「清空记忆」。

**召回**：`memory.search(question, k)`

```
score = 3 × sim + 0.6 × exp(−ageDays / 10)
sim   = |tokens(question) ∩ tokens(turn)| / √|tokens(turn)|
```

- 复用 `retriever.tokenize`：中文按字 + 二元组、英文按词；
- **要求 `sim > 0`**，即字面确有交集才召回，避免任何问题都带上一轮；
- 新鲜度只用于在同等相关度之间排序（半衰期 10 天）。

**组装**：`memory.context(question, maxTurns, maxChars)`

```
【历史对话记忆】这些是你之前问过、与本次相关的问答。只用于保持前后一致，不要当作新的数据来源：
1) 2026-10-05 问：…
   答：…
```

- 默认 3 轮，可在界面上调 1–8 轮；
- 字符上限默认 1500，并且**不超过本次上下文预算的 25%**，保证证据块仍占大头；
- 同一批召回的轮次还会作为 `type: 'memory'` 的事实交给模型，本地引擎会渲染成
  「你之前问过相关的，可以连起来看：」一段，云端模型则同时走 `payload.history`。

## 5. 上下文组装顺序

`retriever.assemble()` 按以下顺序在预算内装填：

1. 用户补充说明（提示词）
2. **历史对话记忆**（≤ 25% 预算）
3. **用户人格画像**（≤ 420 字符）
4. 检索到的证据块（剩余预算）

人格画像长这样：

```
【用户人格画像 · 本机推断的五大人格（OCEAN），只用于调整语气与侧重，不要当作诊断】
- 开放性（O）72/100，偏高，置信度 45%：愿意看到多种解释与可能性
- …（其余四个维度）
- 沟通偏好：偏好简短回答；经常提到具体数字，回答时给出数值更有帮助；常问的指标：心情、睡眠
```

## 6. 持久化与 .me 目录

| 位置 | 键 / 文件 | 内容 |
| --- | --- | --- |
| localStorage | `moodhub.v1.me.personality` | 五大人格 |
| localStorage | `moodhub.v1.me.profile` | 称呼、常问指标 |
| localStorage | `moodhub.v1.me.memory` | 全部问答轮次 |
| 磁盘 | `.me/personality.json` | 同上（手动同步后） |
| 磁盘 | `.me/memory/turns.jsonl` | 一行一轮 |

浏览器**永远不写磁盘**（页面没有、也不该有文件系统权限）：

```bash
node tools/me-sync.cjs export ./me-export.json   # 浏览器导出 → .me/
node tools/me-sync.cjs import ./me-import.json   # .me/ → 可导回浏览器的 JSON
node tools/me-sync.cjs status                    # 概览
```

`.me/.gitignore` 只放行 `README.md` 与 `*.template.json`，真实数据一律不进版本库。
`store.exportAll()` 也会带上 `me` 段，整机备份 / 恢复一并覆盖。

## 7. 界面（智能问答页）

- 提问卡片新增两个开关：**参考历史对话**、**带上我的人格画像**，以及召回轮数下拉；
- 「我的 · .me」卡片：五条维度条（分数 / 档位 / 置信度 / 依据一句话）、记忆概览、最近 5 轮折叠列表；
- 操作：导出 .me、导入 .me、重置人格、清空记忆（后两者需二次确认）；
- 回答卡片底部会出现「参考了 N 轮历史对话」「带上了人格画像」标记，本次没写入记忆时也会说明。

## 8. 边界与验收

| 边界 | 行为 |
| --- | --- |
| 危机文本 | 不写记忆、不参与人格推断，直接走求助通道 |
| 记忆上限 | 200 轮，超出丢最旧 |
| 上下文预算 | 记忆 ≤ 25%，人格 ≤ 420 字符，证据块优先 |
| 召回门槛 | `sim > 0`，无交集不召回 |
| 人格分数 | 恒在 0–100，置信度恒在 0–1，样本只增不减 |
| 开关关闭 | 不进上下文、不更新人格；记忆照常写入 |
| 清空 | 人格回 50 分中性、记忆清空，不可撤销 |
| 导入非法文件 | 抛错并提示，不破坏现有数据 |
| 外发 | 本地模型零请求；云端模型仅在显式授权后直连，记忆 / 人格同样受此约束 |

回归：`node tests/me.cjs`（67 项），或 `node tests/run-all.cjs` 跑全部 5 个套件。
